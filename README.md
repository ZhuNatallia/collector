# AI-комплектатор интерьеров (MVP)

Русскоязычная рабочая область: загрузка изображения, интерактивные метки демонстрационного анализа, подбор товаров по трём бюджетам, ведомость, наценка и экспорт. В каталоге есть вручную сверенные карточки мебели, светильников, ковров, текстиля и декора с российских и белорусских сайтов (в том числе Hoff, Divan.ru, Maytoni, БелКа, La Prima, Textile Home, Витебские ковры и 3D Dom). Цены сверены 20.11.2026 и указаны в валюте магазина.

## Разработка

```bash
npm install
npx next dev
```

## Supabase

Примените `supabase/schema.sql`, настройте `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`. Схема содержит проекты, найденные объекты, каталог, позиции сметы, RLS и функцию косинусного поиска `match_furniture`.

## Текущий предел демо

Демо-данные работают без API-ключей. Для вручную добавленных карточек цены и наличие не обновляются автоматически, поэтому сверяйте их на сайте продавца; у каталожных карточек используются условные миниатюры, а ссылки ведут на реальные модели. Цены и наличие могут меняться; товары из BYN и RUB считаются в смете отдельно. Сегментация пока использует mock; импорт поставщика читает количество строк локально. Список backend-контрактов находится в `app/api-contract.md`. Для реальных SAM/YOLO, эмбеддингов, marketplace-фидов и постоянной индексации нужны серверные функции и ключи провайдера.
